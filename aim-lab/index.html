Data & simulation notes

20 weapon profiles from Valorant-API, retrieved October 22, 2026. Community data snapshot, not guaranteed to match every live patch. Fire rates, magazine, reload, equip, damage ranges, ADS zoom and first-shot spread use the snapshot. Negative API sentinel values are normalized to zero spread / one pellet.

ADS transition, recoil, recovery, movement acceleration, burst spacing, pellet distribution and Odin ramp are approximations. Burst average rates use API data; within-burst gaps are calibrated separately. Outlaw partial reload and Bucky airburst are approximations. Wall penetration is shown for reference; no wallbang simulation. No abilities, network latency, tagging, jumping, reserve-ammo economy or full game physics. Standard weapon artwork: Riot Games, via Valorant-API. Weapon view is a 2D illustration, not a 3D model. Audio is synthesized. This is an independent fan trainer, not Riot Games or Aim Lab.
